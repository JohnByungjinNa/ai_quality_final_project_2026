# Agent Quality Rubric (10-point scale)

## 공통 점수 해석

| 점수 | 판정 | 공통 기준 |
|---:|---|---|
| 10 | 탁월 | 모든 필수 기준 충족, 사실 오류·누락 없음, 재작업 불필요 |
| 9 | 매우 우수 | 핵심 기준 충족, 결과에 영향 없는 경미한 표현 문제만 존재 |
| 8 | 우수 | 목적 달성, 작은 누락이나 불명확성이 있으나 바로 사용 가능 |
| 7 | 양호 | 핵심 결과는 맞지만 일부 보완 후 사용하는 것이 안전함 |
| 6 | 보통 | 부분적으로 유효하나 중요한 항목 하나 이상 수정 필요 |
| 5 | 경계 | 절반 정도 충족, 주요 누락·불일치로 그대로 사용하기 어려움 |
| 4 | 미흡 | 일부 결과만 맞고 업무 활용에 상당한 재작업 필요 |
| 3 | 불량 | 핵심 역할 대부분 실패, 우연히 맞은 일부 정보만 활용 가능 |
| 2 | 심각 | 결과가 거의 무관하거나 오류가 많아 활용 불가 |
| 1 | 실패 | 결과 없음, 호출 실패, 형식 파손 또는 핵심 역할 완전 실패 |

## Agent별 배점

### Interpreter (10점)

| 평가 항목 | 배점 | 만점 기준 |
|---|---:|---|
| 질문 의도(task) | 3 | summary, policy, both를 기대값과 동일하게 해석 |
| 검색 키워드(filters) | 3 | 핵심 검색어를 빠짐없이 추출하고 무관 키워드 없음 |
| 카테고리·조건 | 2 | 검색 범위, 최대 건수, CSV 조건을 정확히 구조화 |
| 기본값·출력 형식 | 2 | 모호·빈 질문에도 안전한 기본값과 유효한 구조 반환 |

상한 규칙: task 오해 시 최대 5점, JSON/응답 파싱 실패 시 최대 2점.

### Retriever (10점)

| 평가 항목 | 배점 | 만점 기준 |
|---|---:|---|
| 재현율 | 4 | 정답셋의 관련 VOC를 빠뜨리지 않음 |
| 정밀도 | 3 | 무관 VOC가 검색 결과에 포함되지 않음 |
| 원문 보존 | 2 | ID와 불만 내용이 변형·손실 없이 전달됨 |
| 한도·성능 | 1 | max_items를 지키고 허용시간 안에 반환 |

상한 규칙: 관련 VOC를 절반 이상 누락하면 최대 5점, 잘못된 CSV 사용 시 1점.

### Summarizer (10점)

| 평가 항목 | 배점 | 만점 기준 |
|---|---:|---|
| 사실 일치 | 4 | 원문과 다른 수치·원인·대상·결론을 만들지 않음 |
| 핵심 포함 | 3 | 주요 불만 유형, 영향, 반복 원인을 빠뜨리지 않음 |
| 중복·간결성 | 2 | 반복 없이 핵심 중심으로 읽기 쉽게 구성 |
| 형식·후보 다양성 | 1 | 요구 후보 수와 출력 형식을 지킴 |

상한 규칙: 중대한 사실 왜곡 시 최대 3점, 근거 없는 내용 생성 시 최대 2점.

### Evaluator (10점)

| 평가 항목 | 배점 | 만점 기준 |
|---|---:|---|
| 기준 일관성 | 3 | 동일 기준을 모든 후보에 동일하게 적용 |
| 우수 후보 선택 | 3 | 정답 또는 사람 평가와 winner가 일치 |
| 점수 타당성 | 2 | 후보 간 점수 차이가 실제 품질 차이를 반영 |
| 결과 형식·재현성 | 2 | winner/scores 형식이 유효하고 반복 평가가 안정적 |

상한 규칙: 존재하지 않는 후보 선택 시 최대 3점, 결과 파싱 실패 시 최대 2점.

### Critic (10점)

| 평가 항목 | 배점 | 만점 기준 |
|---|---:|---|
| 실제 문제 탐지 | 4 | 삽입된 사실 오류·누락·모순을 정확히 탐지 |
| 위험·한계 탐지 | 2 | 고객·운영·정책 위험과 근거 부족을 지적 |
| 수정 지침 구체성 | 2 | 위치와 수정 방법이 명확한 edits 제공 |
| 오탐 억제 | 2 | 문제가 없는 결과를 불필요하게 수정하지 않음 |

상한 규칙: 중대한 위험을 놓치면 최대 5점, 형식적 표현만 반환하면 최대 4점.

### Improver (10점)

| 평가 항목 | 배점 | 만점 기준 |
|---|---:|---|
| VOC 근거 연결 | 3 | 각 개선안이 확인된 VOC 문제와 직접 연결됨 |
| 구체성 | 2 | 담당 조직, 조치, 대상, 방법이 명확함 |
| 실행 가능성 | 2 | 현실적인 자원·절차 안에서 실행 가능함 |
| 측정 가능성 | 2 | 기간, KPI, 완료·성공 기준이 포함됨 |
| 우선순위 | 1 | 영향도·긴급도에 따른 순서가 명확함 |

상한 규칙: VOC와 무관한 제안은 최대 4점, 실행 주체·조치가 모두 없으면 최대 5점.

## 판정 구간

| 점수 | 판정 |
|---:|---|
| 9.0~10.0 | PASS — 우수 |
| 8.0~8.9 | PASS — 사용 가능 |
| 7.0~7.9 | CONDITIONAL PASS — 보완 후 사용 |
| 5.0~6.9 | FAIL — 주요 개선 필요 |
| 1.0~4.9 | FAIL — 재설계·재시험 필요 |

중대한 사실 왜곡, 개인정보 노출, 장애를 성공으로 보고한 경우에는 점수와 관계없이 FAIL로 판정한다.
