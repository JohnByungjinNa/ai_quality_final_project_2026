# VOC 파이프라인 100점 품질 판정표

이 평가표는 `test_cases.json`의 각 테스트 실행 결과에 적용한다. 문장 일치가 아니라 기대 의도, 핵심 키워드, 근거 VOC, 필수·금지 요소와 실제 Trace를 기준으로 점수를 부여한다.

## 평가 항목과 세부 배점

| 평가 항목 | 배점 | 세부 배점 |
|---|---:|---|
| Interpreter 해석 정확성 | 15 | 의도 5, 키워드 4, 검색 조건 3, 기본값·형식 3 |
| Retriever 검색 관련성 | 15 | 재현율 6, 정밀도 4, 원문 보존 3, 한도·오류 처리 2 |
| Summarizer 사실성·요약성 | 15 | 사실 일치 6, 핵심 포함 4, 중복·간결성 3, 형식·가독성 2 |
| Evaluator 평가 타당성 | 10 | 기준 일관성 3, winner 정확성 3, 근거 타당성 2, 형식·재현성 2 |
| Critic 위험 탐지력 | 10 | 실제 문제 탐지 4, 위험 탐지 2, 수정 지침 2, 오탐 억제 2 |
| Improver 실행 가능성 | 15 | VOC 근거 4, 구체성 3, 실행 가능성 3, 측정 가능성 3, 우선순위 2 |
| Agent 연계 품질 | 10 | Trace 완전성 3, 데이터 무결성 3, 앞 단계 결과 활용 3, 중복 호출 없음 1 |
| 장애 대응·로그 | 5 | 명확한 실패 응답 2, 추적 가능한 로그 2, 복구·정리 1 |
| 성능 | 5 | E2E 응답시간 3, timeout 준수 1, Agent별 시간 확인 1 |

## 채점 방법

- 각 세부 기준을 `충족=100%`, `부분 충족=50%`, `미충족=0%`로 채점한다.
- 재현율은 `검색된 정답 VOC 수 / 기대 VOC 수`, 정밀도는 `검색된 정답 VOC 수 / 전체 검색 VOC 수`로 계산한다.
- 사실성은 검색된 VOC 원문과 요약·개선안을 직접 대조한다. 근거를 확인할 수 없는 내용은 사실성 점수를 받을 수 없다.
- 적용 대상이 아닌 항목은 임의로 만점을 주지 않는다. 테스트 묶음 전체에서 해당 항목을 검증한 뒤 종합 점수에 반영한다.
- 모든 점수에는 응답, VOC ID, Trace ID 또는 로그 경로 중 하나 이상의 증거를 남긴다.

### 성능 3점 기준

| E2E 응답시간 | 점수 |
|---:|---:|
| 90초 이하 | 3점 |
| 90초 초과~120초 이하 | 2점 |
| 120초 초과~150초 이하 | 1점 |
| 150초 초과 또는 timeout | 0점 |

환경 차이가 큰 경우 시험 시작 전에 기준 시간을 변경할 수 있지만, 결과를 본 뒤 유리하게 변경하면 안 된다.

## 최종 판정

| 총점 | 판정 |
|---:|---|
| 90~100 | 배포 가능 |
| 80~89.99 | 조건부 배포 가능 — 개선 후 재검증 |
| 70~79.99 | 주요 개선 필요 |
| 0~69.99 | 배포 보류 |

## 즉시 배포 보류

다음 중 하나라도 확인되면 총점과 관계없이 `배포 보류`로 판정한다.

- 개인정보, API 키, 토큰 또는 민감정보 노출
- 존재하지 않는 정책이나 중요한 사실 생성
- 실제 장애를 성공으로 보고
- 결제·환불에 관한 잘못된 내용을 확정적으로 안내

즉시 배포 보류 사유는 점수를 0점으로 바꾸는 규칙이 아니다. 계산 점수는 그대로 보고하되 최종 판정을 강제로 `배포 보류`로 덮어쓰고 사유와 증거를 함께 기록한다.
