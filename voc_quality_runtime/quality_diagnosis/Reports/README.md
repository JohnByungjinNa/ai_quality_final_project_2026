# 품질진단 Report 저장소

품질진단을 실행하면 보고서가 목적별 하위 폴더에 저장된다.

| 폴더 | 내용 |
|---|---|
| `Summary/` | 전체 또는 선택 실행의 종합 결과 |
| `Validation/` | 테스트케이스 20개와 100점 평가표 구조 검증 |
| `Fault/` | 6개 장애 주입 시험 결과와 관측 오류 |
| `A2A/` | 실제 VOC Trace별 Agent 간 gRPC 호출·핵심 키워드 |
| `VOC/` | 사용자가 저장을 선택한 실제 VOC 질문·요약·정책·Trace |

각 폴더에는 실행 시각이 포함된 이력 파일과 가장 최근 결과인 `latest.md`, `latest.json`이 생성된다. A2A 보고서는 Markdown만 생성한다.

보고서에는 API 키, 토큰, VOC 원문 또는 개인정보를 기록하지 않는다.
