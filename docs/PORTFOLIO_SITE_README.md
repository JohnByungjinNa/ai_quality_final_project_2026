# 나병진 개인 포트폴리오

금융권 인프라 보안, 서버·네트워크 운영, AI Agent QA & Monitoring 교육 프로젝트를 공개용으로 정리한 정적 포트폴리오입니다.

참고 페이지와 다른 시각 언어를 사용해 에디토리얼·벤토형 레이아웃으로 재구성했습니다. 내용과 경력 수치는 유지하고, 테마 전환·프로젝트 필터·현재 섹션 표시를 추가했습니다.

페이지 구성은 다음과 같습니다.

- Hero: 핵심 포지셔닝과 운영 철학
- At a glance: 주요 경력 지표
- Profile: 강점과 업무 원칙
- Career log: 대표 경력 기록
- Selected work: 프로젝트 필터와 검증 결과
- Capabilities: 역량과 기술 목록
- Contribution: 기여 가능한 역할
- Contact: Google Form 비공개 문의 채널

## GitHub Pages 공개 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 `index.html`, `styles.css`, `script.js`, `README.md`를 저장소 루트에 올립니다.
3. 저장소의 `Settings → Pages`에서 `Deploy from a branch`를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/ (root)`로 설정하고 저장합니다.
5. 필요하면 `index.html`의 연락 안내 영역에 GitHub 프로필 주소를 추가합니다.

GitHub 사용자명은 확인되지 않아 넣지 않았습니다. 문의는 공개 이메일·전화번호 대신 Google Form 비공개 문의 채널로 연결했습니다. AI Agent QA & Monitoring의 수치는 상용 서비스 실적이 아닌 교육용 시범 프로젝트 결과로 표시했습니다.
